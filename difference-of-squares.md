# Difference of Squares

The difference of squares is a common factoring pattern.

The general form is:

```text
a² - b²
```

It factors as:

```text
(a - b)(a + b)
```

## Example

Consider:

```text
x² - 25
```

Since:

```text
25 = 5²
```

we can write:

```text
x² - 5²
```

Using the difference of squares pattern:

```text
(x - 5)(x + 5)
```

## Another Example

Consider:

```text
9x² - 16
```

Both terms are perfect squares:

```text
9x² = (3x)²
16 = 4²
```

Therefore:

```text
9x² - 16 = (3x - 4)(3x + 4)
```

## How to Recognize It

Look for two perfect-square terms separated by subtraction.
