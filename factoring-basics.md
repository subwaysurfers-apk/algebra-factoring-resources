# Factoring Basics

Factoring is the process of rewriting an algebraic expression as a product of simpler expressions.

## Simple Example

Consider:

```text
x² + 5x + 6
```

This can be written as:

```text
(x + 2)(x + 3)
```

To check the result, multiply the factors:

```text
(x + 2)(x + 3)
= x² + 3x + 2x + 6
= x² + 5x + 6
```

## A Useful First Step

When factoring an expression, first check whether all terms have a common factor.

For example:

```text
6x + 12
```

Both terms are divisible by 6:

```text
6(x + 2)
```

## Common Factoring Methods

Depending on the expression, you may use:

- Greatest Common Factor
- Factoring trinomials
- Difference of squares
- Difference of cubes
- Perfect square trinomials

Practice is important because recognizing the structure of an expression makes the correct method easier to identify.
