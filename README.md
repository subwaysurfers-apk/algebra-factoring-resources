# Algebra & Factoring Resources

Free learning resources for students, teachers, and anyone
who wants to improve their algebra skills.

## Topics

- Factoring basics
- Greatest Common Factor
- Prime factorization
- Factoring trinomials
- Difference of squares
- Difference of cubes
- Perfect square trinomials

## Online Practice

For interactive, step-by-step factoring practice, visit:

[Factoring Calculator Online](https://factoringcalculatoronline.com/)

The calculator provides tools and explanations for practicing
different factoring techniques.

## Learning Resources

This repository contains simple examples and explanations
designed to make common algebra topics easier to understand.
